## Структуры данных и алгоритмы

- **Список покупок:** `list` сохраняет порядок добавления; удаление по названию выполняет линейный поиск, O(n). Добавление в конец обычно O(1).
- **Анализатор текста:** `Counter` — словарь частот. Подсчет всех слов в среднем O(n), где n — число слов; сортировка для топ-5 — O(k log k), где k — число уникальных слов.
- **Маршруты:** `dict[str, list[str]]` хранит список соседей каждого города. BFS использует FIFO-очередь `deque`, посещенные вершины запоминаются в словаре `previous`. Время работы O(V + E), память O(V), где V — вершины, E — связи.

Props/state в этой лабораторной не используются: задания реализованы на Python и демонстрируют подходящие для задачи коллекции.
